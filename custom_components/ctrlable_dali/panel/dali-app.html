Buses

Each DALI master (hasseb) is a bus. A bus is identified by its fixtures, so swapping USB ports doesn't reshuffle entities. Name a new bus, confirm an ambiguous match, or reassign if two got crossed.

On/off, brightness, and (for DT8 tunable-white) colour temperature. Rename a fixture with ✎. Group rows appear here when a group has members.

Group control

Raw DALI frame

Send a raw 2-byte DALI frame — address byte, then opcode. Pick a preset or type the bytes. For queries, the address byte selects the target (short 0 = 1; short N = N·2+1).
→ cmd/res

Scenes

A scene is a preset stored inside each fixture. Set the room how you like it live, open a scene and press Capture — or fine-tune each fixture by hand. Recall fires them all together. Name scenes for easy association.
